# 산길 트레킹 GPS 실사용 검증 (검증용 APK)

## 준비
1. 기존 앱 삭제 및 기록 초기화 금지. 앱 내 '전체 기록 백업'으로 JSON 파일을 먼저 보관.
2. GitHub Actions의 **GPS 거리 정확도 개선 브랜치**에서 성공한 최신 실행의 **SIGNED-UPDATE-APK** 아티팩트만 내려받아 ZIP 압축 해제 후 설치.
3. 설치 오류가 나오면 기존 앱을 삭제하지 말고 오류 화면 캡처. 앱 서명키/패키지명이 다를 수 있음.
4. 위치 설정: 정확한 위치 허용, 위치 서비스 켜기, 배터리 최적화 제한 확인. 트랭글도 같은 조건으로 기록.

## 현장 테스트
- 동일 산행을 트랭글과 산길 트레킹에서 동시에 시작/종료. 시작 및 종료 시각을 각각 기록.
- 열린 하늘에서 5분, 숲길에서 10분, 정지 상태에서 3분, 화면 꺼짐 상태에서 10분 이상 확인.
- 실제 걸은 길과 지도 경로를 비교하고 긴 직선, 강/산 능선 횡단, 지그재그, 정지 중 거리 증가, 기록 누락 여부 확인.
- 앱 종료 후 기록 저장 여부 확인. 기존 기록은 삭제하지 않기.

## 주의
- 30m 정확도 제한은 수목/절벽 지형에서 유효 GPS 점을 누락시킬 수 있음. 테스트 결과를 보고 조정.
- 거리 차이 자체는 출발/종료 시간, 일시정지, 경로 수집 간격 차이도 반영. 동일 시각 비교 필수.
- 현재 테스트는 코드 정적/시나리오 검사 + APK 빌드 검사이며 실기기 검증은 별도 수행해야 함.

# Google Play 출시 자료 — 승인 전 작성본

## 앱 기본 정보
- 앱 이름: 산길 트레킹
- 카테고리 제안: 건강/운동 (Play Console에서 최종 선택)
- 언어: 한국어
- 가격 제안: 무료 (운영자 최종 선택)
- 현재 패키지: `kr.sangil.myhiking.preview` — 출시 패키지 미확정

## 짧은 설명
걷기·달리기·산행 경로와 거리, 활동 기록을 한곳에서 관리하세요.

## 자세한 설명
산길 트레킹은 걷기, 달리기, 산행 중 이동한 경로를 지도에서 확인하고 활동 기록을 관리하도록 돕는 앱입니다.

GPS를 활용해 이동 경로와 거리를 기록하고 활동별 기록을 구분하여 확인할 수 있습니다. 휴대폰 위치 권한과 기기 상태에 따라 위치 기록의 정확도와 지속성이 달라질 수 있습니다.

주요 기능
- 걷기·달리기·산행 모드
- GPS 이동 경로와 거리 표시
- 활동 기록 저장 및 확인

※ 앱 기능과 표시 문구는 실제 휴대폰 검증 결과에 따라 출시 전 조정합니다.

## 이미지 제작 사양
- 고해상도 앱 아이콘: 512×512 PNG
- 대표 그래픽: 1024×500 PNG/JPG
- 휴대폰 스크린샷: 실제 실행 화면, 권장 2장 이상

- 데이터 보안 설문
- 위치 및 포그라운드 서비스 권한 설명

- 테스트 트랙 및 계정 유형별 출시 요건

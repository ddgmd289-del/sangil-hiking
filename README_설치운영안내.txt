산길 v2 통합 등산 앱 (PWA) / 2026-11-10

1. 구성
index.html: 산행 GPS 및 지도, 등산 기록, 안전, 동호회/대회 화면
extensions.js: 동호회/일정/회원, 대회/선수/현장 출석 및 승인, 점수, CSV, 통합 백업
manifest.webmanifest / icons: 홈 화면 설치 설정
service-worker.js: 앱 기본 화면 오프라인 캐시 (지도는 인터넷 필요)

2. 휴대폰 실사용 방법
(1) ZIP 압축 해제 후 파일과 icons 폴더를 HTTPS 웹 호스팅에 그대로 업로드합니다.
    예: GitHub Pages, Cloudflare Pages, Netlify 등에 정적 사이트로 배포.
(2) 휴대폰 브라우저로 https://.../index.html 주소에 접속합니다.
(3) iPhone Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치 또는 홈 화면에 추가
(4) 산행 시작 후 GPS 위치 권한을 허용합니다. 지도 열람에는 인터넷이 필요합니다.

3. 현재 동작하는 기능
GPS 산행 시작/일시정지/종료, 거리/시간/고도, 경유지 표시, GPX 내보내기, 산행기록 저장,
동호회/회원/산행일정 등록·조회·삭제, 대회/3인조 A/B/C 선수 등록, 중복검사,
선수별 출석 확인, A/B/C 3명 모두 출석 시 심판 승인, 개인 점수 입력과 조별 합계,
대회결과 CSV, 통합 JSON 백업/복원, PWA 설치.

4. 중요 제한사항
- 데이터는 각 단말기 브라우저 localStorage에만 있습니다. 서로 다른 기기는 자동 동기화되지 않습니다.
- QR 생성 라이브러리는 인터넷 연결이 필요합니다. QR은 로컬 식별 코드이고 타 기기 자동 출석이 아닙니다.
- 기존 Google Apps Script QR 이론평가 서버와 아직 연동되어 있지 않습니다.
- 여러 심판의 동시 승인/실시간 자동채점/통합 관리자 대시보드는 서버와 인증 기능이 필요합니다.
- GPS는 웹 브라우저가 백그라운드에서 종료되면 누락될 수 있습니다. 구조·안전 목적의 전문 GPS기기를 대체하지 않습니다.
- 산행 개인정보/선수 이름이 로컬에 저장됩니다. 공용 PC에서 사용하지 말고 백업을 안전하게 보관하세요.
- 앱 아이콘·셸은 오프라인에서 동작할 수 있지만 지도 타일과 외부 Leaflet/QR 라이브러리는 첫 로딩 시 인터넷 필요.
- 실제 현장 대회 운영 전에 대표 기기들로 충분한 시험이 필요합니다.

5. 다음 단계 (실운영 확장)
운영자/심판/선수 계정, 공용 데이터베이스, HTTPS 서버, QR 식별 토큰 검증,
기존 QR 이론시험 Apps Script 접속 URL 및 인증과 연동, 실시간 승인/자동채점/중복 승인 방지,
개인정보 처리 방침 및 권한 관리, 산행 GPS 백그라운드 기록(네이티브 앱 검토).
